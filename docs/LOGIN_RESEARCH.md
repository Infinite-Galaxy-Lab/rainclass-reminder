# 单手机微信登录取证

2026-11-09。用户要求单手机、无 root；官方账号密码和验证码入口按用户要求暂缓。

## 已确认

alpha.8 的官方二维码确认链接实验已被真机反证：在微信文件传输助手点开后，仍要求扫码或提示不允许。
不要重复要求用户测试相同入口，也不能把 MuMu 后台扫码成功当作单手机登录成功。

用户提供了 SicnuJw 的“绑定川师微生活”截图，含“分享至微信”“复制链接”和回调链接 / code 手动兜底。
截图属于授权过程，原图、二维码、完整链接和随机回调标识均留在仓库外。

| 流程 | 匿名取证 | 尚缺环节 |
|---|---|---|
| alpha.8 二维码确认链接 | 微信 `/connect/confirm`，真机点开失败 | 不再作为可用的单手机入口 |
| 川师微生活 | 学校 `/api/wechat/auth` 返回 302，转微信 `/connect/oauth2/authorize`，scope 为 `snsapi_userinfo`，授权回调仍在学校域名 | 截图所示 App 回调、code 兑换和绑定代码 |
| 雨课堂微信网页授权 | 官方前端的微信浏览器分支指向 `/login/weixinapp/`；匿名请求返回相同类型的 OAuth 授权，回调为本站 `/complete/weixinapp/` | 在微信授权后把有效雨课堂会话交回 Android 的方式 |

学校入口只用研究用回调地址发出 HEAD，未访问截图中的真实会话；雨课堂入口只作匿名 GET，未请求账号授权。
只保留状态码、域名、路径、查询参数名和 scope，不记录 OAuth state、Cookie 或授权码。

上述差异说明截图展示的是另一条授权流程，不能通过给旧确认链接随意添加参数来推定等价。
同一网站在微信中完成授权，也不能证明独立 Android HTTP client 或 WebView 已获得其 Cookie。

## 源码范围

SicnuJw 当前公开 main 快照为 `5d10e9826144d92d163bfef1596d31976f9d01c7`。
2026-11-09 17:55 +08 抓取后，公开分支仍只有 main；其 130 个跟踪文件没有截图所示微生活绑定、
`frontUrl` 回调或对应分享入口。现有代码的登录是内嵌官方 CAS 与双因子页面。
这仅说明当前公开快照缺少相关实现，不能据此否认用户所用安装包具有该功能。

雨课堂依据来自官方公开 `authorize` 前端：认证失败处理在微信浏览器中跳转到
`/login/weixinapp/?next=...`。匿名取证确认该入口存在；未修改 redirect_uri、借用学校 AppID，
也未将第三方学校接口接入本项目认证。

## 继续条件

取得与截图对应的分支、提交或本机源码后，先查授权链接生成、回调接收、code 兑换和会话存储。
只有雨课堂也具备可验证的会话交接方式，才在独立验证包接入。保持认证与只读业务端点分离，
成功仍须通过现有非零身份校验并加密保存；不把分享链接、打开微信或收到任意 code 视作登录成功。

账号登录的未完成改动已备份在仓库外，源码与本地 AAR 恢复为 alpha.8 基线；没有发行 alpha.9。
本轮仅更新取证与待办，不改变二维码轮询、已确认的后台恢复、课程同步或业务映射。

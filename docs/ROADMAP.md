# 版本与验收计划

截至 2026-11-09。当前发布仍为 Go 守护进程和本地 WebUI，新增平台按 [ADR 0001](adr/0001-platform-clients.md) 分阶段推进。

| 阶段 | 交付 | 通过条件 | 当前状态 |
|---|---|---|---|
| P1 / P3 / P4-1 | 课件判据回退、面板同名折叠、成绩 | 回归与反向验证，保留逐课堂提醒 | 已合入 main |
| P2 工具 | 被动观察、脱敏报告、登录自启 | 不增加业务请求；重启不延长 24h 抓取；假数据与启动器验证 | 桌面已重登取得成功样本，11-09 11:06:36 起观察 24h；下次登录触发与网页侧另待验 |
| P2 结论 | 本地导入后的可用时长、官方网页刷新行为 | 连续观察到明确失效，区分断网/重登/休眠；网页另采样 | 待观察，不能预填结论 |
| A0 Android 可行性 | 最小 AAR 与 Worker 原型 | ADR 的五项关卡，真机通知与登录 | 双 ABI AAR、SQLite、10 项模拟器测试通过；真机待验 |
| W1 Windows GUI | Wails 窗口、托盘、现有面板 | 单引擎、鉴权、退出/重连/升级回滚测试 | 未开始 |
| A1 Android 内测 | 原生列表、登录、刷新、本地提醒 | API 最低版本、权限说明、离线/杀进程/省电测试 | alpha.3 放大二维码并允许截图，11 项设备回归通过；真实登录、微信相册识别与物理手机后台待验 |
| R1 正式发行 | Windows 包、Android 签名 APK、校验和 | CI、干净安装与旧版升级、隐私复核、恢复演练 | 依赖 W1 / A1 |

不同时重写核心与 UI。W1 与 A0 可在稳定接口后并行，Android 的未验证能力不能写成已支持。iOS 暂列后续评估，当前范围是 Windows 和 Android。

## 合并与发布

- 功能分支使用 `codex/` 前缀，围绕一个可验收结果提交；正常提交经全量验证推入 main。
- 合入 main 不等于创建发行版；只有平台验收、升级/回滚和材料齐备后打版本标签。
- 变更端点、解析器、数据库或提醒策略时更新 API_NOTES / ARCHITECTURE；每轮结束更新 HANDOFF 与此表。
- 新增回归必须实际破坏对应实现取得断言失败，再恢复全绿；编译失败不算。真实账号材料保持仓库外，不把其内容复制进测试。

## 验证矩阵

| 范围 | 必须覆盖 |
|---|---|
| 核心 | Go tests / vet / gofmt，Linux、Windows、macOS CI，既有纯 Go 构建 |
| 面板 | Node 纯逻辑测试；布局变动再测桌面与窄屏 |
| 观察工具 | Python stdlib 测试，白名单脱敏、坏尾行、24h 跨重启；Windows 启动器用合成进程验证 |
| Windows GUI | WebView2、托盘、单实例、后台服务升级、旧库迁移 |
| Android | AAR 绑定、NDK 构建、系统版本/设备范围、通知权限、省电、重启、断网与退出登录 |

项目与运行数据的备份、恢复边界见 [OPERATIONS.md](OPERATIONS.md)。
